# Industrial Defect Detection — C++/OpenCV

钢材表面缺陷检测(传统机器视觉路线),数据集:**NEU-DET**(东北大学钢材表面缺陷库,6 类 ×300 张官方 / 本仓库配套 1770 张含标注镜像子集,200×200 灰度)。

## Pipeline

1. 预处理:灰度化 → 高斯/中值滤波 → 直方图均衡(低对比度/反光场景)
2. 缺陷分割:阈值(Otsu)/边缘(Canny)+ 形态学连接 / 顶帽变换 + blob —— 按缺陷形态选策略
3. 特征提取 + 分类:连通域分析 + 几何/灰度特征 + 规则分类(后续扩展 SVM)
4. 评估:批量测试 → Precision / Recall / 准确率 + 可视化标注图

> 状态:**完成**(2026-09-07,阶段 0-4 + 评估收尾)。这个仓库的定位不是"传统方法打赢深度学习",而是:完整工程化地实现传统视觉管线(CMake/C++17/OpenCV/CLI,全 git 追踪),系统量化它的能力边界(图像级分类 96.9% 可用 → 实例级检出不可靠),并为"何时必须上深度/无监督方法"给出数据支持——详见下方开发记录。

## 开发记录(阶段结论)

### 阶段 2:缺陷分割(2026-09-07)

批量评估:**60 张(每类 10 张,seed 固定)× 3 策略**,命中口径 = GT 框内缺陷像素占比 ≥ `max(1%, 2× 全图缺陷占比)`(相对密度,防止"全图报警"刷出虚高命中率)。

| 缺陷类 | Otsu | Edge | Black-hat | 结论 |
|---|---|---|---|---|
| In 夹杂 | 1/43 | 20/43 | **32/43 (74%)** fg 11.9% | hat 可用 |
| Sc 划痕 | 0/22 | **14/22 (64%)** fg 18.1% | 11/22 | edge 可用 |
| Cr 裂纹 | 0/22 | 0/22(全图刷白 99.9%) | 0/22 | 纹理型,像素级不可分 |
| PS 麻点 | 1/14 | 0/14 | 1/14 | 散布型,不可分 |
| RS 铁皮压入 | 0/20 | 0/20 | 2/20 | 散布型,不可分 |

结论:
1. **单策略 + 固定参数打不了 6 类**——缺陷形态决定可分性维度(现实对应:按钢种/缺陷族配参数,即"视觉配方")。
2. 像素级分割可用上限:**In→black-hat、Sc→edge**,命中率 64-74% 且误检面(fg)控制在 12-18%("少而准")。
3. Cr(网纹)/PS(麻点)/RS(压入铁皮)缺陷与背景无灰度/梯度可分性,GT 大方框是"区域声明"——需转**特征级**(纹理/形态特征分类)。
4. 方法论:绝对命中率第一版全线 100%(实为全图报警),加相对密度口径后现原形;**评估必须先定义"检出"的含义**,这是做 P/R 前的第一课。

复现命令:
```
./build/defect_detector batch <清单.txt> <mask目录>   # C++ 批量分割
python scripts/batch_hitrate.py --per-class 10        # Python 命中率评估
```

### 阶段 3:特征提取 + 缺陷分类(2026-09-07)

单图 18 维特征:灰度统计 2(mean/std)+ GLCM 纹理 4(32 级量化、4 方向对称化,contrast/energy/homogeneity/correlation)+ 三策略 mask 形态 12(fg 占比/连通域数/平均面积/最大面积,otsu/edge/hat)。`defect_detector features`(C++)批量出 CSV → Python RBF-SVM,固定 seed 分层 80/20(按图划分,防同图泄漏),StandardScaler 只在训练集上拟合。

**结果:test acc 96.9%**(1416 训练 / 354 测试)。消融:去掉 GLCM 损失最大、glcm-only 仍有 89.3% → **纹理特征是 Cr 裂纹从像素级不可分到可分类的关键**(对阶段 2 结论 3 的修正:像素级不可分 ≠ 特征级不可分)。

复现命令:
```
./build/defect_detector features <清单.txt> results/eval/features.csv
python scripts/train_classify.py    # 分类 + 消融 + confusion.png
python scripts/visualize_preds.py   # 人眼核验页(每个误判样本:真值框 | 模型预测)
```

### 阶段 4:候选框检测——传统方法实例级检出边界(2026-09-07)

把分类器升级到"能自己画框":GT 框内 patch 为正样本、随机避开 GT 的区域为背景负样本,训 7 类(6 缺陷 + BG)框级 SVM(`defect_detector patchfeat` 对任意矩形 patch 提同 18 维特征);测试帧经三策略分割后每个连通域 = 候选框,分类保留下非 BG 者即检测框;再加**帧级门控**(阶段 3 图像级分类器先限定本帧允许类别,工业"粗筛-复核"两段式)。判分严格:IoU≥0.5 **且同类别**才为 TP,漏检/错类记 FN,无匹配框记 FP,逐类 P/R/F1。

| class | TP | FP | FN | precision | recall | F1 |
|---|---|---|---|---|---|---|
| Cr 裂纹 | 12 | 54 | 122 | 18.2% | 9.0% | 12.0% |
| In 夹杂 | 19 | 203 | 187 | 8.6% | 9.2% | 8.9% |
| Pa 斑块 | 26 | 81 | 144 | 24.3% | 15.3% | 18.8% |
| PS 麻点 | 53 | 156 | 30 | 25.4% | **63.9%** | 36.3% |
| RS 铁皮压入 | 4 | 25 | 121 | 13.8% | 3.2% | 5.2% |
| Sc 划痕 | 28 | 188 | 73 | 13.0% | 27.7% | 17.7% |

整体 P=16.7% R=17.3%(354 测试帧,12 帧完全干净;无门控时 P 仅 2.9%——候选框约 90% 是钢材纹理噪声,帧级门控 + 调高 BG 权重是主要抑制手段)。

结论:
1. **通用传统检测到不了实例级可靠检出**:纹理类(Cr/RS)分割阶段即丢失,recall 低是真实瓶颈;散布类(PS/Sc)漏检少但误报无法用统计特征压干净。逐帧可视化(results/eval/detect/,左真值框|右模型框,绿=命中红=错)可直接人眼核验。
2. **两处数据局限必须诚实说明(也是本实验最有价值的部分)**:
   - NEU-DET **没有 OK(无缺陷)帧**,1770 张全为缺陷图 → 只能做"缺陷归类",真实产线的 OK/NG 检出环节从未被测试;
   - GT 框是"代表区声明"而非穷尽标注(如 PS 帧框外同样满布麻点)→ 框外真实缺陷被判 FP,**P 的下界被标注意外抬高**,不能当算法真实精度读。
3. **选型证据链闭合**:图像级可分类(96.9%)→ 实例级不可靠检出 → 而工业界真正稀缺的正是 OK 图充足场景下的检出 —— 这就是项目转向深度/无监督方法(WinCLIP, MVTec-AD)的直接论据。

复现命令:
```
./build/defect_detector patchfeat <patch清单> out.csv      # 框级特征
python scripts/detect_boxes.py --bg-weight 4 --bg-per-img 6   # 检测+评估+逐帧图
```
